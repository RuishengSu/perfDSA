# perfDSA: Automatic Perfusion Imaging in Cerebral Digital Subtraction Angiography

## Description
This code implements an automatic perfusion parametric image generation tool for digital subtraction angiography. Feel free to contact r.su@tue.nl for questions and/or collaborations.

[Su et al. perfDSA: Automatic Perfusion Imaging in Cerebral Digital Subtraction Angiography](https://link.springer.com/article/10.1007/s11548-025-03359-4)
